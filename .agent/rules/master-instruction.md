Project Context: Lexicon (Vocabulary Builder App)

Role: You are an Expert Full-Stack Architect and Developer specializing in Generative AI integration.

Project Goal: Build a web application called "Lexicon" that helps B1-B2 English learners improve their vocabulary while reading difficult books (e.g., "Ho Chi Minh: A Life"). The app automates the extraction of difficult vocabulary from book page images and creates study materials (definitions, contexts, images).

1. The "One-Shot" AI Pipeline

We are skipping traditional OCR preprocessing. The raw image file (HEIC/JPG) is sent directly to a Multimodal LLM.

Input: User uploads a book page image via the Frontend.

Processing: The Backend sends the image to AWS Bedrock (Claude 3.5 Sonnet or Gemini 1.5 Pro).

AI Task: The model performs OCR, filters for B1/B2+ level words, extracts context, generates definitions, and creates an "Image Search Query" for each word.

Image Fetch: The Backend takes the "Image Search Query" and calls Serper API to get a relevant image URL.

Storage: The structured data is saved to the database.

2. Tech Stack

Frontend: Next.js (React, App Router, Tailwind CSS).

Backend: NestJS (Node.js, TypeScript).

AI Integration: AWS Bedrock SDK (Model ID: anthropic.claude-3-sonnet-20240229-v1:0 or gemini-1.5-pro-001).

Search API: Serper API (Google Images).

Database: PostgreSQL (recommended) or SQLite (for local dev), managed via Prisma ORM.

State Management: React Query (TanStack Query) for fetching data.

3. User Experience (UX) Requirements

Lookup System: The user must be able to find vocabulary lists using flexible indices found in Kindle devices or physical books.

Input Field: "Page/Location"

Supported Formats: "Page 45", "Loc 2431", "Chapter 5".

Capture Flow: Simple mobile-first upload button.

Review Flow: A Flashcard mode to review saved vocabulary.

4. Data Schema Strategy

Book: id, title, author, cover_image.

PageEntry: id, book_id, page_number (string, to handle "Loc 2431"), image_url (stored uploaded image), created_at.

Vocabulary: id, page_entry_id, word, definition, context_sentence (from the book), image_search_query (generated by AI), image_url (from Serper), mastery_level (0-5 for spaced repetition).

5. The "Instructor" Prompt for AWS Bedrock

Use this exact logic when calling the AI Model:
"Analyze the attached image of a book page.

OCR the text.

Identify 5-10 vocabulary words suitable for a B1-level English learner (ignore common A1/A2 words).

For each word, return a JSON object with:

word: The vocabulary word.

definition: A simple, clear definition fitting the context.

context: The exact sentence from the text where the word appears.

image_query: A short, descriptive 3-4 word search query to find a visual representation of this word (e.g., 'dictator speaking podium' for 'demagogue').
Return ONLY a JSON array."

Setup: Initialize Next.js and NestJS repos. Configure AWS Bedrock connection.

API: Build the /upload endpoint in NestJS to handle the Image -> Bedrock -> Serper flow.

UI: Build the Upload Page and the "Book Reader" view (Lookup by Page/Loc).

Review: Build the Flashcard logic.

Generate the necessary boilerplate code and folder structure based on these requirements.
